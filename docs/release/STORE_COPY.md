## Name

Chronos · 柯罗诺斯

## Short description

为生活留下一段时间，用彩色手账看见每一天。

## Shared description

一键记录正在做的事。工作、阅读、运动或休息，都可以拥有自己的颜色。

- 开始、暂停、继续和结束，按实际计时累计。
- 用时间轴和手账查看记录，为活动补充分类与备注。
- 补记过去的活动，按日期浏览历史和七天变化。
- 数据默认存储在本机，主动导出 JSON 备份或 CSV。
- 恢复前先检查，合并相同记录，冲突时保留原内容。
- 三套外观和跟随系统模式。

手动记录与手机使用可能重叠，因此分开统计。留白仅表示没有记录，不代表没有活动。当前版本无需账号，免费使用。
